FAQ & Bantuan
Cara upload video

1. Klik area upload atau drag file
2. Tunggu proses upload selesai
3. Copy kode yang muncul
4. Kirim .claim KODE di grup WhatsApp

Cara claim di grup

1. Join grup claim yang tersedia
2. Kirim .claim KODE
3. Bot akan kirim file dalam beberapa detik
4. Kode yang expired tidak bisa di-claim

Berapa lama kode valid?

Kode valid sesuai pengaturan admin (default 60 menit). Setelah expire, file otomatis dihapus.

Format file yang didukung?

Video: MP4, MKV, AVI, MOV, WEBM, 3GP
Foto: JPG, PNG, GIF, WEBP
Dan semua format file lainnya.

Cara join grup claim

1. Scroll ke bawah halaman upload
2. Klik link grup WhatsApp yang tersedia
3. Join grup tersebut
4. Setelah join, kamu bisa claim file dengan mengirim .claim KODE

Video patah / kualitas turun?

Video yang dikirim via WhatsApp akan dikompresi oleh WA. Tips:
• Upload video 720p untuk hasil terbaik
• Gunakan format MP4 H.264
• File besar (>16MB) akan di-compress WA secara otomatis

Apakah file aman?

File otomatis dihapus setelah expired. Tidak ada yang bisa mengakses file tanpa kode claim. Server tidak menyimpan data pribadi.

Butuh bantuan?

Hubungi admin via WhatsApp — link tersedia di bawah halaman upload. Atau chat langsung di grup claim.
